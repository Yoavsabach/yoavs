# הסכמים משרדיים (user-examples)

תיקייה זו מיועדת להסכמי שכירות מסחרית אמיתיים של המשרד (מואנמים — ללא שמות
לקוחות, ת.ז. וסכומים מזהים). כל קובץ md/docx/pdf שיונח כאן ישמש את הסוכן
כבנצ'מרק ובסיס ניסוח מועדפים על פני הדוגמאות הסינתטיות ותבניות-האב.

> ⚠️ **המאגר הזה (GitHub) ציבורי — אין להעלות לכאן את הסכמי המשרד.**
> הקבצים המשרדיים נשמרים רק בעותק המותקן של הסקיל (ובחבילת ההתקנה `.skill`
> שנארזת מקומית). לפני אריזת גרסה חדשה להתקנה — העתיקו לתיקייה זו את קבצי
> ה-user-examples מהעותק המותקן הקיים.

מומלץ לשם הקובץ: `<segment>-<landlord/tenant>-<year>.md`
לדוגמה: `office-tenant-2025.md`

הוספה: שלחו את ההסכמים לקלוד בצ'אט ובקשו "הוסף ל-user-examples של סוכן
השכירות המסחרית וארוז מחדש", או הוסיפו ידנית לפני התקנת ה-.skill.
