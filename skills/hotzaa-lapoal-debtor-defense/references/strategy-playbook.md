# מנוע האסטרטגיה — עצי החלטה לייצוג חייב

> להרצה בשלב 3 של ה-Workflow. התוצר: מסמך אסטרטגיה מדורג ללקוח. כל ענף מפנה
> לתבנית ב-`motions-library.md` ולטופס ב-`forms-catalog.md`.

## עקרונות-על

1. **קודם לעצור את הדימום**: עיקול משכורת/בנק פעיל והגבלת רישיון קודמים לכל
   דיון עקרוני על החוב. פעולה דחופה ביום הראשון.
2. **לא לוותר על תקיפת החיוב**: לפני כל הסדר — האם קיימת עילת התנגדות/פרעתי/פגם
   דיוני? הסדר על חוב שניתן היה לבטלו הוא כישלון ייצוגי.
3. **כל בקשה בונה נרטיב**: חייב משתף פעולה, שקוף, ששילם כמיטב יכולתו — זה
   הנרטיב שמנטרל "השתמטות" (התנאי להגבלות) ומשיג צווי תשלומים ריאליים.
4. **מדרג הסלמה**: בקשה לרשם → עיון חוזר → ערעור/בר"ע (20 ימים). לעולם לציין
   ללקוח את השלב הבא אם הבקשה תידחה.
5. **חדל"פ היא אופציה אסטרטגית, לא כישלון**: ריבוי תיקים + חוב בלתי ניתן לפירעון
   בפריסה סבירה ⇒ שקול שיקום כלכלי מוקדם ככל האפשר.

## עץ החלטה 1 — התקבלה אזהרה (חלון המועדים פתוח)

```
מה מקור החיוב?
├─ שטר / שיק (ס' 81א)
│   ├─ יש עילת הגנה (זיוף, כשלון תמורה, פירעון, התיישנות,
│   │   מילוי בניגוד להרשאה, אחיזה שלא בתום לב)?
│   │   ├─ כן → התנגדות לביצוע שטר בתוך 30 יום [תבנית 7]
│   │   │        + הגשה במועד מעכבת הליכים אוטומטית
│   │   └─ לא → צו תשלומים בתוך תקופת האזהרה [תבנית 10]
│   │            או מו"מ להסדר מול ב"כ הזוכה [תבנית 14]
├─ תביעה על סכום קצוב (ס' 81א1)
│   ├─ נשלח מכתב התראה 30 יום מראש? הסכום "קצוב" באמת?
│   │   ├─ פגם → התנגדות הכוללת את הפגם הדיוני [תבנית 8]
│   │   └─ תקין → יש הגנה מהותית (שירות לא סופק, קיזוז, פירעון)?
│   │       ├─ כן → התנגדות בתוך 30 יום [תבנית 8]
│   │       └─ לא → צו תשלומים / הסדר
├─ פסק דין
│   ├─ ניתן במעמד צד אחד ולא ידעת על ההליך?
│   │   → בקשת ביטול פס"ד לערכאה שנתנה אותו + עיכוב ביצוע שם
│   │     + בקשת השהיית הליכים לרשם [תבנית 9]
│   ├─ פסק הדין קוים/נפרע (מלוא/חלק)?
│   │   → טענת "פרעתי" ס' 19 [תבנית 6]
│   └─ אין תקיפה → צו תשלומים בתוך תקופת האזהרה [תבנית 10]
└─ משכנתא / משכון
    → בדוק פיגור אמיתי, דרישת פירעון כדין, הגנות דירת מגורים
      (ס' 38, 81ב1) → בקשות בהתאם + מו"מ להסדר פיגורים
```

## עץ החלטה 2 — הוטל עיקול

```
מה עוקל?
├─ משכורת (צד ג' - מעסיק)
│   ├─ העיקול חודר לשכר המוגן (ס' 8 חוק הגנת השכר)?
│   │   → בקשה דחופה לביטול/צמצום עיקול [תבנית 1]
│   ├─ קיים צו תשלומים שהחייב עומד בו? → ביטול — ההליך נוגד את הצו
│   └─ תמיד: לחשב את הסכום המוגן לפי הרכב משפחתי + לצרף תלושים
├─ חשבון בנק
│   ├─ בחשבון קצבאות ב"ל / הסכום המוגן הבסיסי? → ביטול חלקי מיידי [תבנית 2]
│   ├─ חשבון משותף עם בן/בת זוג שאינם חייבים? → טענת צד ג' לגבי מחציתם
│   └─ העיקול משתק שכר נכנס? → שילוב עם בקשת צו תשלומים
├─ רכב
│   ├─ חיוני לפרנסה / רכב נכה / שוויו זניח מול הוצאות מימוש?
│   │   → בקשת ביטול עיקול רכב [תבנית 3]
│   └─ בבעלות צד ג' (בן משפחה, ליסינג)? → הודעת צד ג' + ביטול
├─ מיטלטלין בבית
│   └─ פריטים מוגנים ס' 22? → ביטול [תבנית 1 מותאמת]
└─ מקרקעין / דירת מגורים
    ├─ עיקול רישומי בלבד → לרוב לא דחוף; לתעד ולטפל במסגרת ההסדר הכולל
    └─ הליכי מימוש/כינוס → הגנות ס' 38 (סידור חלוף), שמאות, מחיר מזערי,
       ולשקול חלופת מימוש עצמי / מחזור משכנתא
```

## עץ החלטה 3 — הוטלו הגבלות (ס' 66א) או עיכוב יציאה (ס' 14)

```
├─ הגבלת רישיון נהיגה
│   ├─ הרישיון חיוני לפרנסה (נהג, שליח, עבודה מרוחקת) או נכות?
│   │   → ביטול לפי הסייג בחוק [תבנית 4] — צרף אישורי מעסיק/רופא
│   └─ אחרת → לבטל דרך שינוי סטטוס: צו תשלומים + עמידה בו / איחוד תיקים
├─ עיכוב דרכון / לקוח מוגבל / כרטיסי אשראי / תאגיד
│   ├─ הוטלה ללא התראה מוקדמת כדין? → ביטול מטעם דיוני [תבנית 4]
│   ├─ החייב אינו "בעל יכולת המשתמט" (אין יכולת אמיתית)?
│   │   → בקשה לחקירת יכולת + ביטול הגבלות [תבניות 4+11]
│   └─ צורך נקודתי (נסיעה רפואית/עבודה/משפחה)?
│       → היתר חד-פעמי כנגד ערובה [תבנית 5]
└─ עיכוב יציאה מהארץ (ס' 14)
    ├─ אין תשתית ל"עומד לצאת מהארץ"? → ביטול מלא [תבנית 5]
    ├─ נסיעה חיונית מתועדת? → היתר יציאה חד-פעמי + ערבות/פיקדון [תבנית 5]
    └─ במסגרת איחוד תיקים? → ביטול עם קבלת צו האיחוד והעמידה בו
```

## עץ החלטה 4 — ריבוי תיקים / חוסר יכולת כוללת

```
כמה תיקים וכמה חוב?
├─ 2+ תיקים, יש יכולת לתשלום עיתי (~3% מסך החובות לחודש — לאמת שיעור)
│   → בקשת איחוד תיקים [תבנית 12] → צו תשלומים אחד, הקפאת הליכים פרטניים
├─ אין יכולת לעמוד גם בכך
│   ├─ סך החובות עד תקרת ס' 105 לחוק חדל"פ (לאמת סכום עדכני)
│   │   → בקשה לצו פתיחת הליכים אצל רשם ההוצל"פ (חדל"פ בסכום נמוך)
│   └─ מעל התקרה → הפניה ל-insolvency-individual-expert (הממונה על חדל"פ)
└─ יכולת חלקית + נכס משמעותי אחד → שקול מימוש עצמי מבוקר / הסדר כולל
   מול הזוכים לפני שהכינוס שוחק את התמורה
```

## טקטיקות מו"מ מול ב"כ זוכה (לשלב ההסדר)

- נקודת פתיחה: עלויות הגבייה לזוכה (כינוס, שמאות, שנים של גבייה טיפין-טיפין)
  מול תשלום מיידי מופחת — הפחתת קרן/ריבית תמורת mzuman היא עסקה רציונלית לזוכה.
- לעולם לעגן הסדר בכתב עם: סכום סופי, מנגנון "סולם" (הפרה מחזירה יתרה), ביטול
  כל ההליכים וההגבלות עם התשלום, וסגירת התיק — לא רק "הקטנת חוב".
- הסדר בתיק איחוד מחייב אישור רשם — לוודא שההסדר לא מפלה זוכים אחרים באיחוד.
