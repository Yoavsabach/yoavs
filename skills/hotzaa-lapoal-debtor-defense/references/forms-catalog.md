# קטלוג הטפסים הייעודיים — רשות האכיפה והגבייה (צד חייב)

> כלל ברזל: **אין להמציא מספרי טפסים או קודי בקשה.** הקטלוג מנוהל לפי שם הטופס
> ותפקידו. לכל טופס קיימת גרסה עדכנית באתר gov.il (רשות האכיפה והגבייה —
> "טפסים" / "שירותים") ולכל סוג בקשה קוד מספרי במערכת הממוחשבת של הלשכות —
> אמת את הקוד והגרסה מול האתר או מול הטופס שנשלח מהלשכה לפני הגשה.

## 1. ערוצי הגשה

| ערוץ | למי | הערות |
|------|-----|-------|
| אזור אישי מקוון (gov.il — הוצאה לפועל) | חייב מיוצג ושאינו מיוצג | הגשת בקשות בתיק, צפייה בתיק, תדפיסים |
| מערכת המייצגים ("כספת" / ממשק עו"ד) | עורכי דין | ההגשה המהירה והמתועדת ביותר — עדיפה |
| לשכת ההוצאה לפועל (דלפק / תיבה) | הכל | חובה חותמת "נתקבל" על עותק |
| מוקד טלפוני ארצי *35592 | בירורים, תיאום תור | לא ערוץ הגשה לבקשות מהותיות |

## 2. טפסי ליבה בייצוג חייב (לפי תפקיד)

| שם הטופס / הבקשה | מתי משתמשים | צרופות חובה |
|------------------|-------------|-------------|
| ייפוי כוח + הודעת ייצוג (עו"ד) | פתיחת ייצוג בכל תיק | ייפוי כוח חתום; ראה תבנית ב-motions-library |
| **התנגדות לביצוע שטר** | תוך 30 יום מהמצאת האזהרה (ס' 81א) | כתב התנגדות מנומק + תצהיר + העתק השטר והאזהרה |
| **התנגדות לביצוע תביעה על סכום קצוב** | תוך 30 יום מהמצאת האזהרה (ס' 81א1) | כתב התנגדות + תצהיר + מסמכי העסקה |
| **טענת "פרעתי" (ס' 19)** | חוב על-פי פס"ד שנפרע/קוים | תצהיר + אסמכתאות תשלום |
| **בקשה לצו תשלומים + הצהרת חייב על יכולת** | בתוך תקופת האזהרה או בכל עת | שאלון/הצהרה מלאה על הכנסות, הוצאות, נכסים וחובות + תלושים, דפי בנק 3 חודשים, חוזה שכירות וכו' |
| שאלון וכתב ויתור על סודיות | נלווה לחקירת יכולת / איחוד תיקים / הפחתת תשלומים | חתימת החייב |
| **בקשה לחקירת יכולת (ס' 67)** | לקביעת/הפחתת תשלומים, סתירת "השתמטות" | ההצהרה והשאלון לעיל |
| **בקשה לאיחוד תיקים (פרק ז'3)** | 2+ תיקים | רשימת כל התיקים + הצהרה + תשלום עיתי ראשון כנדרש בחוק |
| **בקשת חייב — כללית** ("בקשה בתיק") | כל בקשה שאין לה טופס ייעודי: ביטול עיקול, ביטול הגבלה, עיכוב הליכים, הקטנת/עדכון חוב, ביטול עיכוב יציאה, היתר יציאה חד-פעמי, הארכת מועד, עיון חוזר | כתב הבקשה המנומק + תצהיר כשנטענות עובדות + נספחים |
| הודעת עדכון פרטים (כתובת/חשבון) | שינוי מען — קריטי להמצאות | אסמכתה |
| בקשה לקבלת תדפיס תיק / דף חשבון | תחילת כל טיפול | — |
| בקשה לפריסת/הפחתת חוב במסלול מקוצר | תיקים בפרק א'1 | לפי דרישת הלשכה |
| תצהיר (נוסח כללי לאימות עובדות) | נלווה כמעט לכל בקשה מהותית | אימות חתימה בפני עו"ד |

בעת הגשה במערכת הממוחשבת בחר את **קוד הבקשה** המתאים מרשימת הקודים שבמערכת
(הרשימה מוצגת בממשק ההגשה) — אל תנחש קוד; קוד שגוי מנתב את הבקשה למסלול שגוי
ומאבד זמן יקר.

## 3. נוהל עבודה עם טופס שהתקבל מלשכת ההוצאה לפועל

כשהלקוח/הלשכה מספקים טופס (PDF, סריקה, צילום) — הטופס שהתקבל **גובר** על כל
תבנית פנימית:

1. **קליטה**: קבל את הקובץ; סריקה/תמונה → הפעל `hebrew-ocr-forms` לחילוץ מלא
   של השדות והטקסט (כולל אותיות סופיות וגרשיים — ת"ז, מס' תיק).
2. **זיהוי**: קבע מהו הטופס (שם, לשכה, מספר תיק, מועד תגובה נקוב) ומה מבוקש
   מהחייב. מועד נקוב בטופס/בהחלטה גובר על ברירות המחדל שבחוק.
3. **מיפוי שדות**: בנה טבלת שדה←ערך מנתוני ה-Intake. שדה חסר → שאל את
   המשתמש; אל תמלא ניחוש.
4. **מילוי**: מלא את הטופס עצמו (עריכת PDF דרך הסקיל `pdf`, או שחזור נאמן
   ב-DOCX דרך `legal-docx` אם ה-PDF נעול) + הכן את כתב הבקשה/התגובה הנלווה
   מ-`motions-library.md`.
5. **בקרה**: בדיקה צולבת — מספר תיק, ת"ז (ספרת ביקורת!), סכומים, תאריכים
   עברי/לועזי, חתימות נדרשות (חייב? עו"ד? מאמת תצהיר?).
6. **הגשה ותיעוד**: הנחה את המשתמש על ערוץ ההגשה הנכון; שמור עותק + אישור
   הגשה; רשום את מועד המעקב הבא.

## 4. אימות עדכניות (חובה לפני כל הגשה)

- אם WebSearch/WebFetch זמינים: חפש באתר gov.il את עמוד השירות הרלוונטי של
  רשות האכיפה והגבייה ואמת: גרסת טופס, סכומים (שכר מוגן, אגרות, תקרת מסלול
  מקוצר, תקרת חדל"פ ס' 105), ומועדים.
- אם אין גישה לרשת: כתוב במפורש בתוצר "לאמת גרסת טופס וסכומים עדכניים באתר
  רשות האכיפה והגבייה לפני הגשה".
- טופס שהופק מהתוספת לתקנות ההוצאה לפועל, התש"ם-1979 — בדוק שהנוסח לא עודכן
  בתיקון תקנות מאוחר.
